# Primary sources

Primary material is cited differently from scholarship, and getting it wrong is
one of the few errors a humanities marker will always catch.

## Establish what is being cited

Ask, if not already clear:

- Which edition or printing does the user physically have?
- Is it a translation, and by whom?
- Does the work have a standard reference system the field uses instead of page
  numbers?
- For archival items: repository, collection, box or shelfmark, item, date?

Never fill these in from memory. An edition guessed wrong invalidates every page
reference built on it.

## Record it once, use it everywhere

Create the literature note with `type: primary` and an `edition` field carrying
the full details. Where the work has a standard reference system, note it in the
frontmatter so later citations use that system rather than page numbers.

Common systems: Stephanus for Plato, Bekker for Aristotle, book and line for
epic and drama, act, scene and line for plays, manuscript or folio numbers for
archival material, section and article for legal instruments, chapter and verse
for scripture, manuscript sheet numerals for unpublished notebooks.

Where the user cites more than one edition of the same work, flag it: mixing
editions produces citations that cannot be checked. Ask which is authoritative
for this project and convert the rest.

## Translations

If the argument turns on a particular word or phrase, say so in the note and
record the original term. Offer to check how other standard translations render
it: a claim resting on one translator's choice is worth knowing about before a
viva rather than during one.

## Quotation discipline

Primary quotations carry the heaviest weight in a humanities argument, so hold
them to the quotation gate strictly: exact wording, exact locator, verified
against the source, with the user's confirmation. Mark alterations with square
brackets and omissions with an ellipsis. Preserve original spelling and
punctuation.

## Report

Tell the user what was recorded, which locator system will be used, anything
left unverified, and whether any edition conflicts were found.
