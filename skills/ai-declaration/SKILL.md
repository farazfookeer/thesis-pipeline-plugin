# AI use declaration

Most institutions now require a statement of how AI was used. An accurate one
protects the user; a vague one invites questions.

## Establish the facts first

Read `00-Admin/reading-queue.md` end to end, plus any supervisor correspondence
in `00-Admin/supervisor-notes/`. Build the record from what actually happened,
not from a template. Establish:

- What the assistant did at each stage: organising, locating, extracting,
  verifying, drafting, checking
- What the user did: reading, deciding the argument, writing, revising, approving
- What permission exists, from whom, and when it was given
- Which gates were enforced: reading gates, quotation verification, provenance

## Then draft

Write to `70-Draft/ai-declaration.md`, in the user's voice, covering:

1. Which tool was used, and for what, stage by stage
2. What the user did themselves, particularly the argument and the prose
3. Any permission obtained, quoting or citing it
4. How accuracy was safeguarded: verification against sources, reading gates,
   the both-ways citation check
5. What was not done: no fabricated sources, no unverified citations, no
   unreviewed generated text in the final document

Keep it specific and checkable. Every sentence should be one the user could
defend in a viva.

## Warnings

- If the record shows generated text that the user never revised, say so and
  tell them to revise it before submitting.
- If the institution's policy is unrecorded in `project-config.md`, tell the
  user to obtain it before submitting the declaration.
- Do not overstate the user's supervision or approval. If permission was verbal,
  say verbal.
