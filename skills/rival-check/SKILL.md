# Rival check

Find out whether the argument already exists in print. Better now than in a viva.

## Method

1. Establish the argument in one sentence with the user: claim, target, and the
   move that makes it distinctive.

2. Identify the key sources it engages: the framework or paper being challenged,
   and the two or three works supplying the critical apparatus.

3. Map who cites those works. Use Google Scholar's citing-articles list,
   Semantic Scholar, CrossRef's citation data, and the databases relevant to the
   field. Search terms should combine the target's vocabulary with the user's
   distinctive move.

4. For each candidate that looks close, get past the abstract. Abstracts hide
   the difference that matters. Read enough to establish which register the
   piece works in.

5. Classify each candidate:
   - **Occupied**: makes the user's argument. Report immediately and prominently.
   - **Adjacent**: same territory, different register or conclusion. These are
     the ones to cite, distinguish, and possibly recruit.
   - **Unrelated**: keyword collision.

## Report

Write `20-Maps/rival-check-(date).md`: the searches run, the databases used, the
candidates found, the classification of each with reasons, and a verdict line:
CLEAR, ADJACENT WORK EXISTS, or OCCUPIED.

Tell the user the verdict in the first sentence of the reply. If a rival exists,
say what remains distinctive about their version, honestly, including the case
that nothing does.

Re-run this before submission if months have passed. New work appears.
